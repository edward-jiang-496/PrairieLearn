Example 2: radio-matrix Graded Ranking Question

The radio-matrix style is also ideal for constructing graded questions with limited selection per row or column.

  • Setting reset-button="true" adds a reset button to the element.
  • Setting max-response-per-option="1" invalidates the submission if a column is selected 2 or more times.
  • Setting min-response-per-option="1" invalidates the submission if a column is left unselected.

Example 3: radio-matrix Ungraded Ranking Survey

The radio-matrix style is also ideal for constructing ungraded ranking survey questions.

  • You can use builtin-grading="false" to disable the grading. In addition, when builtin-grading="false", all options need to be explicitly defined with pl-option or preset options.
  • allow-blank="false" means students must choose an option per row.
  • Setting reset-button="true" adds a reset button to the element.
  • Setting max-response-per-option="2" invalidates the submission if a column is selected 3 or more times.
  • Setting min-response-per-option="1" invalidates the submission if a column is left unselected.

Example 4: radio-matrix Ungraded Survey

The radio-matrix style is ideal for constructing ungraded survey questions.

  • You can use builtin-grading="false" to disable the grading. In addition, when builtin-grading="false", all options need to be explicitly defined with pl-option or preset options.
  • allow-blank="true" permits students to submit without selecting an option.
  • Furthermore, you can use preset-options="agreement-5" to use predefined Likert agreement-5 options.
  • When repeat-header="1,3" is set, the radio-matrix repeats the options header in a repeating "header, 1 row, header, 3 rows" pattern.
  • Setting reset-button="true" adds a reset button to the element.

 The course creates clear learning objectives3 that are both challenging and attainable, and intersect with the overall course goals. The course Designs student-centered learning and assessment experiences that support the learning objectives. The course provides readily available, coherently organized, and high quality course materials (including syllabi) that establish student workload, learning objectives, performance criteria, grading procedures, and class policy expectations. The course organizes and manages class time and students' activities in and out of class to yield high levels of student learning. The course models and fosters critical, analytical, and creative thinking. The course communicates content clearly with students. The course has constructive and timely written and oral communication with students. The course gives timely, useful, and fair feedback on activities and assignments tied to performance criteria and learning objectives.
